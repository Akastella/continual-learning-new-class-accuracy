# Separate calibration and test analysis after the fixed-history interventions

Written while the added models are still training and before any test outputs from the three new conditions. The training PLAN.md and its execution remain unchanged. This CPU analysis asks whether restoring a current-image all-class loss changes the attainable old/new decisions, or mainly the balance of two sets of scores. It will use saved logits after all new training has completed, without more network training or labels.

## Images and comparison

Split the 10,000 official CIFAR-100 test images once by original class. For each original class 0–99, permute its 100 official indices with NumPy PCG64 seed 2026110800 + class; use the first 20 as calibration and the remaining 80 as test. These identities are shared by every model and seed. The 2,000 calibration images comprise 1,800 old and 200 current images at task 9; the 8,000 test images comprise 7,200 old and 800 current images. These labeled calibration images are additional to the training memory and do not train network parameters. The complete official test source has been used in the broader project; the split is held out from fitting, not a previously untouched research dataset.

Compare original ER, zero all-class current term, 5% all-class current term, mixed-replay full current loss, and mixed-replay restricted current loss for each of the five paired seeds. The original common-current-only model can be reported as an additional reference but is not part of a claim about the training intervention. Retain all models and unavailable targets.

For each individual model add one common scalar b to all ten current-class logits. No other score or parameter changes. For a required old accuracy q = 5, 10, 15, 20, 25, 30 percent, select the largest b whose calibration old accuracy is at least q + 3 percentage points. The 3-point margin is fixed here and is descriptive, without a distributional guarantee. As before, the scalar is the corresponding order statistic among old images whose within-old winning class is correct. An old/current tie favors the old class. If the within-old accuracy is below q+3, the target is unavailable; do not drop that seed from availability counts or substitute another target. Report actual test old, new, all accuracy, per-old-task accuracy, and violations of q. Report unadjusted endpoints and within-group accuracies as well. Fit each model individually, without using test scores to select a method or scalar.

## Interpretation and refutation

The incoming-loss explanation predicts a severe raw score change when no current positives receive a full-class loss. This does not by itself imply a better or worse attainable retaining classifier. If a scalar substantially restores unrestricted new predictions while meeting the test old target, the raw collapse alone is evidence about score balance, not a need to relearn new-class distinctions. Conversely, offsets cannot improve within-group decisions. Persistent differences between test tradeoffs after fitting, with actual old levels and violations reported, demonstrate changes beyond the original scalar balance. Compare paired test values only on the explicitly stated common feasible seed sets, and also show all five seeds and failures. Do not call unequal actual retention levels an equal-retention improvement, or infer statistical equivalence from small descriptive differences.

This analysis deliberately compares the standard score adjustment with the newly trained conditions. No bias family, image split, margin, target, or interpretation criterion will be tuned on the new test outcomes.
